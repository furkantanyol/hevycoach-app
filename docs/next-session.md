- **Driving the simulator from a session.** Do not use `System Events click at`: it resolves the point to the iOS accessibility element under it and presses at that element's centre (a tap "outside" the card landed on the full-screen backdrop's centre, inside the card, for an hour). Post a raw click instead; this Swift program did it (compile once with `swiftc -O click.swift -o rawclick`):

  ```swift
  import Foundation
  import CoreGraphics
  let args = CommandLine.arguments
  let pt = CGPoint(x: Double(args[1])!, y: Double(args[2])!)
  func post(_ type: CGEventType) {
    CGEvent(mouseEventSource: nil, mouseType: type, mouseCursorPosition: pt, mouseButton: .left)!.post(tap: .cghidEventTap)
  }
  post(.mouseMoved); usleep(120_000)
  post(.leftMouseDown); usleep(70_000)
  post(.leftMouseUp)
  ```
